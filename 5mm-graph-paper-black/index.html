Questions about black graph paper

Does printing the black background waste a lot of ink?

A full black page uses noticeably more toner than a white one — most of the sheet is covered. If ink is a concern, print one sheet first, and set your print dialog to “Draft” or “Eco” mode if your printer offers it. The grid stays perfectly usable.

Can I write on it in pencil after printing?

Yes, though a soft white or light pen reads best. For pencil work people usually prefer the cream version, which is nearly as kind to the eye but costs far less ink.

Is the black version really the same grid as the white one?

Exactly the same geometry — same line spacing and same measuring bars. Only the background changes, so swap freely between the three colour versions without re-learning the grid.

How do I verify this prints at the true size?

Lay a ruler on the two bars in the bottom margin — the upper must read 100 mm and the lower 4 inches. If both are short by the same amount, the print dialog scaled the page: set it to 100% / Actual Size and print again.
